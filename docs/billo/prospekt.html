EU-Compliance

Alle Pflichtfelder nach §14 UStG — automatisch

Billo kennt die gesetzlichen Anforderungen und befüllt alle Pflichtfelder automatisch. Du musst nichts vergessen — Billo erinnert dich.

✓
Rechnungsnummer
Fortlaufend, eindeutig, keine Lücken. Format: RE-2026-001
✓
Rechnungsdatum & Leistungsdatum
Beide Daten nach §14 Abs. 4 Nr. 6 UStG Pflicht
✓
Vollständige Adressen
Lieferant und Leistungsempfänger mit Straße, PLZ, Ort
✓
USt-ID / Steuernummer
Wenn regelbesteuert: USt-ID oder Steuernummer des Lieferanten
✓
Netto / MwSt. / Brutto
Alle Beträge einzeln ausgewiesen, Steuersatz je Position (0%, 7%, 19%)
✓
IBAN + BIC
Zahlungsinformationen für Überweisungen — aus deinem Profil
✓
§19 UStG Hinweis (Kleinunternehmer)
Automatischer Pflichttext wenn Kleinunternehmer-Modus aktiv: „Gemäß § 19 UStG wird keine Umsatzsteuer berechnet."

Feature-Highlights

Was Billo außerdem kann

👆
Swipe-Gesten
Swipe-Right auf ein Angebot konvertiert es zur Rechnung. Swipe-Left für Optionen wie Löschen oder Duplizieren.
➕
FAB-Schnellzugriff
Floating Action Button öffnet sofort den Rechnung-erstellen-Dialog. Neues Angebot oder Rechnung in 3 Taps.
🔄
Angebote → Rechnungen
1-Tap Konvertierung. Nächste Rechnungsnummer wird automatisch vergeben. Original-Angebot bleibt gespeichert.
📊
Multi-MwSt.-Sätze
Jede Position hat einen eigenen Steuersatz (0%, 7%, 19%). Billo berechnet Netto/MwSt./Brutto automatisch.
📤
Teilen via Android
PDF-Rechnung teilen per E-Mail, WhatsApp, Messenger oder in beliebige andere Apps — über den Standard-Android-Share.
🌑
AMOLED Dark Mode
Echtes Schwarz auf AMOLED-Displays spart Akku. Optimiert für moderne Android-Geräte.
