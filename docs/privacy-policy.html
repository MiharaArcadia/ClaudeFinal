🦀 Carby – Datenschutzerklärung

Zuletzt aktualisiert: Juni 2024

1. Überblick

Carby ist eine kostenlose Ernährungs-Tracking-App. Datenschutz ist uns wichtig. Diese Erklärung beschreibt, welche Daten wir erheben und wie wir sie verwenden.

2. Erhobene Daten

Daten, die lokal gespeichert werden

  • Lebensmittel-Tagebuch: Deine erfassten Mahlzeiten werden lokal auf deinem Gerät gespeichert (Shared Preferences / electron-store).
  • Profildaten: Name, Alter, Gewicht, Größe, Kalorienziel – nur lokal auf deinem Gerät.

Daten, die an externe Dienste gesendet werden

  • Lebensmittelsuche: Suchanfragen werden an OpenFoodFacts gesendet (Open-Source-Datenbank). Es werden keine personenbezogenen Daten übertragen.
  • Spracheingabe (Desktop): Audiodaten werden zur Transkription an die Hugging Face Inference API (Whisper-Modell) gesendet. Die Daten werden nach der Verarbeitung nicht gespeichert.
  • Firebase (Mobile App): Die mobile App nutzt Firebase für anonyme Benutzer-IDs und die Synchronisation des Lebensmittelprotokolls. Es werden keine E-Mail-Adressen oder persönlichen Informationen gespeichert.

3. Keine Werbung, kein Tracking

Carby enthält keine Werbenetzwerke, kein Cross-App-Tracking und keine Analyse-Tools von Drittanbietern. Wir verkaufen keine Nutzerdaten.

4. Berechtigungen

  • Mikrofon: Nur für die Spracheingabe-Funktion. Wird nur aktiv, wenn du auf den Mikrofon-Button tippst.
  • Internet: Für Lebensmittelsuche (OpenFoodFacts) und Spracheingabe (Whisper API).

5. Deine Rechte (DSGVO)

Du hast das Recht auf:

  • Auskunft: Welche Daten über dich gespeichert sind.
  • Löschung: Alle lokalen Daten werden gelöscht, wenn du die App deinstallierst. Firebase-Daten können über die App-Einstellungen gelöscht werden.
  • Datenportabilität: Deine Daten gehören dir.

6. Kinder

Carby richtet sich nicht an Kinder unter 13 Jahren. Wir erheben wissentlich keine Daten von Kindern.
